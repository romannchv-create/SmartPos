# SmartPos

SmartPos is a lightweight Geometry Dash Geode mod that automatically sets up StartPos objects for you.

Whenever you place or move a StartPos, SmartPos scans the portals before it and applies the correct player state automatically. This means you can spend less time configuring StartPos settings and more time building and testing your level.

Whether you're creating a small level or a large project with dozens of StartPos objects, SmartPos helps keep testing fast, consistent, and frustration-free.

## Features

- Automatically detects the correct gamemode.
- Automatically detects gravity.
- Automatically detects mini mode.
- Automatically detects speed.
- Works instantly when placing a new StartPos.
- Updates StartPos settings whenever the StartPos is moved.

## Why use SmartPos?

Normally, every StartPos has to be configured manually. Forgetting to change even one setting can cause the player to start in the wrong state, making level testing confusing and slowing down development.

SmartPos removes that extra work. Simply place or move a StartPos and continue building—everything else is handled automatically.

## Future Plans

SmartPos is still actively being developed. Planned improvements include support for additional gameplay-changing objects, more accurate StartPos detection, and even more automation to make creating and testing Geometry Dash levels easier.

## Installation

Once the mod is available on the Geode Index, simply install it through Geode.

Until then, you can download the latest release from the GitHub Releases page and install it manually.
